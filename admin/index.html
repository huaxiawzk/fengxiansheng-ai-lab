2 · 图片资源

图片按路径引用（如 assets/qr-helper.svg 或你上传后的 assets/uploads/xxx.png）。换图有两种方式：
· 直接把新图覆盖到仓库 assets/ 同名文件（沿用原文件名即立刻生效，无需改文案）；
· 或上传新图到 assets/uploads/，再把内容里的路径改成该文件路径。

保存后 GitHub 会自动触发一次重新部署，约 1 分钟线上生效。若只是改文案，可直接刷新首页看结果。
